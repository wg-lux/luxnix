# WG-Lux MCP agent guidance

- Treat files and repositories as the source of truth.
- Use MCP tools for just-in-time retrieval and progressive disclosure.
- Start with repository and context discovery before reading full files.
- Prefer compact results with repository, path, commit, and line provenance.
- Retrieve exact source sections only when the evidence is needed.
- Keep tools narrowly scoped, read-only, and non-overlapping.
- Preserve architectural decisions, invariants, unresolved bugs, and blockers.
- Compact completed work into outcomes and evidence; discard redundant tool output.
- Never claim that this service can modify files, Git state, services, or databases.
